# 隐私说明

最后更新：2026-09-02

## 简短说明

PerfectPlan 是离线优先的个人计划桌面应用。应用不要求账号，不提供默认云同步，也不内置广告、行为分析或遥测 SDK。你的任务、备注、项目、标签、日程和提醒默认只保存在当前设备。

## 本地保存的数据

为实现计划功能，应用在本机 SQLite 数据库中保存你输入或创建的内容，包括：

- 任务标题、备注、完成状态、优先级、日期与时间安排；
- 项目、标签、子任务和重复规则；
- 本地提醒及其稍后提醒状态。

具体数据库位置及安全备份方式见 [安装、数据与手动备份](./INSTALLATION.md)。

## 我们不收集的内容

当前版本不会自动收集或上传：

- 任务内容、日历安排或提醒内容；
- 使用时长、点击行为或设备使用分析；
- 姓名、邮箱、电话号码或账号资料；
- 广告标识符或跨应用追踪信息。

## 何时会发生网络访问

核心功能无需网络。只有你主动打开 GitHub 链接、访问官网、下载 Release 或提交 Issue 时，浏览器或 GitHub 会按其自身隐私政策处理相应的访问数据。PerfectPlan 本身目前不会把任务数据传给 GitHub 或其他第三方。

## 本地提醒

提醒由操作系统的本地通知能力提供。应用会在你允许通知权限后显示提醒；提醒会在应用运行期间触发。PerfectPlan 当前不使用远程推送服务，完全退出应用后不保证提醒继续触发。

## 数据控制

你可以随时卸载应用、删除本地数据库或手动备份并恢复数据库。请在操作前完全退出应用，并自行妥善保护备份副本，因为备份可能包含完整的个人任务内容。

自动备份、JSON 导入导出与 CSV 导出目前尚未提供；我们不会把这些尚未实现的能力描述为已可用功能。

## 本说明的变更

如果未来引入账号、云同步、遥测、第三方服务或新的联网权限，我们会先更新本说明、产品文档和发布说明，并在实现前记录相应技术决策。

## 联系与反馈

请通过 [GitHub Issues](https://github.com/ssbsunshengbo/PerfectPlan/issues) 提交公开的产品反馈。请勿在公开 Issue 中粘贴真实任务内容、数据库文件、证书、令牌或其他敏感信息。
