# PerfectPlan 产品优化执行计划

> 状态：依据竞品调研于 2026-09-03 重定优先级。完整证据、取舍与来源见 [竞品体验研究](./report-source.md)。

## 产品方向

PerfectPlan 是一款离线、免费、个人使用的桌面计划工具。下一阶段的价值不是增加更多模块，而是让用户轻松完成：**记下任务、看清今天、安排时间、重新找到任务**。

体验原则：

1. 任务标题和下一步行动优先于控件；
2. 计划日期、截止日、具体时间块三者有明确的不同语义；
3. 属性按需展开，避免重表单和控件墙；
4. 日历旁保留可安排任务池；
5. 菜单栏是低打扰的便携工作台，不是缩小的主窗口。

## 分批执行

| 批次          | 核心目标                                     | 主要范围                                             | 验收结果                                                           |
| ------------- | -------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------ |
| 0. 样板与系统 | 定义正确的视觉语言，而非先全局换色           | token、输入/选择器/标签/浮层、任务行和详情页样板     | 详情页层级清晰，组件可在主窗口与便携版复用。                       |
| 1. 捕捉闭环   | 将“写下→补充→完成/改期”做轻                  | 快速添加、`#标签`、任务详情、任务行、即时反馈        | 创建带标签和计划时间的任务不需长表单；任务行可直接读出归属与时间。 |
| 2. 每日与整理 | 让今日、收集箱、即将到来、项目和标签各司其职 | 行动顺序、筛选状态、项目/标签浏览、轻量工作量提示    | 用户两分钟内可捕捉、选重点、改期并按项目/标签找回任务。            |
| 3. 时间块     | 将日历打磨为可靠的执行安排工具               | 任务池、半小时拖拽、完整时长预览、冲突展开、完成态   | 预览与最终落点一致；冲突任务仍可读、可点、可编辑。                 |
| 4. 便携与收尾 | 完成菜单栏闭环和发布级品质                   | 菜单栏任务面板、相邻详情、macOS/Windows 回归、无障碍 | 不打开主窗口也可创建、查看、改期和完成今日任务。                   |

## 当前进展

- 批次 0、1 已完成：视觉组件基线、快速添加、标签输入、任务详情与任务行已完成第一轮整理；完成的任务和子任务会保留可见状态。
- 批次 2 进行中：从项目和标签页开始，将“管理入口”改为可直接找回任务的整理入口。

## 当前起点

从 **批次 0 + 批次 1** 开始，以“任务详情页、任务行、快速添加”作为一个完整可验收切片。先在真实数据、浅/深主题、窄窗口和菜单栏便携版中验证，再扩展到今日和日历；不在此期间加入同步、外部日历、AI 解析、番茄钟、习惯或协作功能。
