# 常见问题

## PerfectPlan 免费吗？

是。PerfectPlan 的核心个人计划能力免费提供：任务、项目、标签、日历、基础筛选、提醒和本地数据不会设置数量限制或订阅墙。

## 需要注册账号吗？

不需要。应用当前没有账号系统，也不依赖服务器。

## 支持多设备同步吗？

当前不支持。每台设备都有独立的本地数据库；不会自动把任务传到另一台电脑、手机或网页端。我们会在核心离线体验获得用户验证后，再评估同步功能。

## 断网还能使用吗？

可以。创建、编辑、完成、安排任务和使用本地提醒等核心功能不需要网络。只有下载应用、访问官网和提交 GitHub 反馈需要联网。

## 应用完全退出后还会提醒吗？

目前不保证。提醒会在 PerfectPlan 运行期间触发；完全退出应用后，MVP 阶段不会让应用常驻或自动启动。这样避免后台常驻、额外系统权限和不透明的电量消耗。

## 我的数据在哪？如何备份？

数据保存在本地 SQLite 数据库中。请参阅 [安装、数据与手动备份](./INSTALLATION.md) 的路径、备份与恢复步骤。当前没有自动备份、JSON 导入导出或 CSV 导出。

## 为什么 macOS 或 Windows 会出现安全提示？

桌面系统会根据安装包签名和发布者信誉提供安全提示。PerfectPlan 正在配置正式的 macOS 签名/公证及 Windows 签名；在完成前，请只从官方 GitHub Releases 下载，并核对项目地址。详情见 [安装说明](./INSTALLATION.md)。

## 如何反馈问题或参与开发？

请在 [GitHub Issues](https://github.com/ssbsunshengbo/PerfectPlan/issues) 提交可复现的问题或建议。开发协作方式见仓库根目录的 [CONTRIBUTING.md](../CONTRIBUTING.md)。不要公开上传含有个人任务内容的数据库文件或截图。
