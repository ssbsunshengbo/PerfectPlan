# ADR-0001：使用 Tauri SQL 插件管理本地 SQLite

- 状态：已接受
- 日期：2026-09-01

## 背景

PerfectPlan 在 MVP 不提供账号或云同步，但必须在用户设备上可靠保存任务，并让未来的备份、导入导出和可选同步可以在不推翻数据模型的前提下演进。

## 决策

使用 Tauri 官方 SQL 插件，并只启用 SQLite 驱动。数据库连接固定为 `sqlite:perfectplan.db`，由插件保存到应用配置目录。数据库 schema 通过 Rust 端的顺序迁移注册；迁移 SQL 存放在 `src-tauri/migrations/`，并随应用二进制发布。

前端不得在功能组件中直接写 SQL。所有数据库访问必须先经过 `src/features/database/`，后续任务领域操作再由 `TaskService` 封装。数据库连接建立时启用 SQLite 外键约束。

## 后果

- 应用可离线运行，且 schema 升级在事务中执行。
- 数据库文件位置由 Tauri 管理，避免前端任意访问文件系统。
- 未来所有 schema 改动都必须新增不可变迁移，并补充升级测试；不得修改已发布迁移。
- 前端 SQL 插件权限仅授予本应用的主窗口。导入导出和备份将使用额外、范围受限的文件权限，而非扩大 SQL 权限。
